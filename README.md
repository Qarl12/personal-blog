## 🖼️ How to Add Your Images

1. Rename your **profile photo** → `profile.jpg` and put it in `assets/img/`
2. Rename your **project screenshots** as shown above
3. Upload everything to GitHub

---

## 🚀 How to Deploy to GitHub Pages

1. Go to your repository `personal-blog` on GitHub
2. Click **Settings** → **Pages**
3. Under **Source**, select `Deploy from a branch`
4. Select branch: `main` → folder: `/ (root)`
5. Click **Save**
6. Your site will be live at: `https://YOUR-USERNAME.github.io/personal-blog/`
